# Setup & Installation

This project uses a simple **JavaScript “Hello World”** example. Follow the steps below to set up the environment.

## Prerequisites

- **Node.js** (recommended: LTS; optionally provide an `.nvmrc` to pin the version)
- **npm** (bundled with Node.js)

> Tip: If you use `nvm`, run `nvm use` in the project root (when `.nvmrc` is present).
##Install dependencies
- **npm install**

**Start app:**
```bash
+ *node src/main.js or node src/utils.js*
